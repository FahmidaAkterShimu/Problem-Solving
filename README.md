## 💻 Example Problem Format

Each problem will generally follow a simple structure:

```javascript
// Problem: Check if a number is even or odd

function isEven(number) {
  return number % 2 === 0;
}

console.log(isEven(10)); // true
console.log(isEven(7));  // false
```

The goal is not only to get the correct output, but also to understand **why the solution works**.
